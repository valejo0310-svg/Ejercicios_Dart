# Proyecto POS Restaurante – Introducción a Dart

## Descripción

Este proyecto forma parte del proceso de formación del SENA y tiene como objetivo aplicar los fundamentos del lenguaje de programación **Dart** mediante ejercicios prácticos basados en las operaciones de un sistema de punto de venta (POS) para restaurante.

## Objetivo

Desarrollar habilidades de programación utilizando variables, operadores, condicionales, ciclos, listas y diccionarios (`Map`) para resolver situaciones relacionadas con la gestión de ventas y caja de un restaurante.

## Ejercicios desarrollados

1. **Apertura de caja:** validación de permisos y registro de movimientos.
2. **Registro de ventas:** cálculo de pedidos, propinas y medios de pago.
3. **Venta con descuento:** aplicación de descuentos, cupones y límites.
4. **Devolución de productos:** validación de cantidades y actualización de ventas.
5. **Cierre de caja:** cálculo de ingresos, egresos y diferencias de efectivo.

## Tecnologías utilizadas

- **Dart:** lenguaje de programación.
- **DartPad:** entorno de ejecución y pruebas en línea.

## Ejecución

1. Ingresar a https://dartpad.dev.
2. Copiar el código del ejercicio que se desea ejecutar.
3. Presionar **Run**.
4. Verificar los resultados y realizar las pruebas adicionales indicadas en la guía.
